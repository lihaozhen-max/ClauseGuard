# 调用端（frontend-or-client）

**M6 实现**。Vue 3 + Element Plus + Vite 单页应用，对应 SPEC FR-UI-01…FR-UI-08。

## 计划页面（设计 §11）

| 模块 | 展示内容 | SPEC |
|---|---|---|
| 待办调用模块 | 审批编号、标题、申请人、申请时间、附件数量、任务状态 | FR-UI-01 |
| 详情查看模块 | 审批基本信息、表单数据、合同附件 | FR-UI-02 |
| 解析结果模块 | 合同基本信息、条款、原文、位置、提取状态（`missing`/`failed` 高亮） | FR-UI-03 |
| 规则命中模块 | 总风险等级、风险数量、规则名、证据、位置、建议（三色区分） | FR-UI-04、NF-10 |
| 结果处理模块 | 评论内容、回写状态/时间/错误，回写与重试按钮 | FR-UI-05 |
| 日志页 | 8 类核心操作日志 | FR-UI-07、AC18 |
| 规则维护页 | 启用/停用、改等级、改建议 | FR-UI-08 |
| 重试入口 | `blocked` 任务人工重试 | FR-UI-06、AC17 |

## 约定

- 开发期端口 `5173`（设计 FIG-02），后端 `127.0.0.1:8000`。
- 所有请求必须带 `X-API-Key: {INTERNAL_API_KEY}`（FR-SYS-03）。
- 合同附件**禁止**在前端通过静态路径访问（FR-SYS-02）。

M0 阶段仅占位；`package.json`/`vite.config.ts` 等在 M6 建立。
