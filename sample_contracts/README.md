## 文本源与再生成

合同的**文本源**在 `sources/*.txt`（`<<<PAGE>>>` 分隔页），是可评审、可 diff 的单一来源。

```powershell
cd ClauseGuard
uv run --project backend python sample_contracts/generate_samples.py
```

生成器同时：

1. 渲染 PDF / 扫描件 PNG / 0 字节异常文件；
2. 导出 `expected_results.json`（SD-01 期望结果，源自 `mock-approval-system/seed.py`，不重复维护）；
3. **校验"一行 = 一段、不折行"**：若某行超宽会被折行，则打印告警并**以退出码 1 失败**。

> 为什么强制不折行：PDF 折行会把句子切断，抽取文本里就不再是连续子串，
> 进而破坏 `position`（第 N 页 第 M 段）与 PS-10 证据回验。详见 `docs/M1-验收记录.md` §3.4。
> 真实合同必然折行，因此 M2 的文本清洗**仍必须**实现折行还原——样例只是把这一不确定因素移出回归基线。

## 硬约束

- **SD-02**：样例合同必须为自造文本，禁止使用真实企业合同数据。
- **SD-01**：每份样例必须随附期望结果，用于 M3 规则引擎回归比对。
