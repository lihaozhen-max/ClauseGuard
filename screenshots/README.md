## 生成方式

由 headless Chrome 对**真实运行的前后端**渲染后截图，非手绘、非拼接：

```powershell
& chrome --headless=new --disable-gpu --hide-scrollbars --window-size=1760,1080 `
   --virtual-time-budget=9000 --screenshot="screenshots\AC01_待办拉取.png" `
   "http://127.0.0.1:5173/tasks"
```

交互态（如新增规则对话框）用一个**临时同源 iframe 夹具**（载入调用端后轮询点击按钮）生成，
夹具在截图后立即删除、不进交付物。详见 `docs/M7-验收记录.md` §3.5。

截图前的库状态由 `scripts/demo_closed_loop.py --reset --all` 铺好（AC01/04/09/14/16/17/18/19
所需状态全部覆盖）；`AC05` 与 `FR-UI-03` 只需在界面上对 AP-003 / AP-002 各点一次
**「触发解析（IF-14）」**（AP-003 为扫描件，约 60–77s）即可复现。

- 每张截图对应 SPEC §13 的一条验收标准（AC01–AC19）或一条 FR-UI，便于逐条核对；

  已入库的截图均不含密钥——密钥输入框仅在点击「接口密钥」后出现，截图时未打开。
